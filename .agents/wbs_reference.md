# 📅 [살고싶오] WBS(작업 분해 구조도) 및 R&R 역할분담 가이드 (Markdown)

본 문서는 프로젝트 WBS 시트(`Sheet1.html`)의 **8주차 마일스톤 일정, 108개 과업 항목, 팀원 5인의 R&R 역할 분담표, FE/BE/QA/Infra 세부 개발 과업**을 완벽히 정리한 전용 마크다운 개발 가이드입니다.

## 🗓️ 1. 주차별 마일스톤 및 일정 (1주차 ~ 8주차)

- **1주차 (7/9 ~ 7/16)**: 기획 확정, 기획안 작성, 시장조사, R&R 분담
- **2주차 (7/17 ~ 7/23)**: Core 설계 & UI/UX 피그마, DB ERD, WBS, 공공 API 사전 검증
- **3주차 (7/24 ~ 7/30)**: Core 완료 (로그인/가입, 온보딩, DB 스키마, 지도 기본 레이아웃) + 2차 멘토링
- **4주차 (7/31 ~ 8/6)**: Main 진행 (위반건축물/연식 매칭, 안심 귀갓길 경로 탐색 & CPTED 감산 알고리즘)
- **5주차 (8/7 ~ 8/13)**: Main 완료 (안전 경로 지도 표시) + 3차 멘토링
- **6주차 (8/14 ~ 8/20)**: 커스텀 필터링(편의시설 도보 제한), 충족 뱃지(`4/5`), 통합 QA 착수
- **7주차 (8/21 ~ 8/26)**: 전체 통합 QA, UI/UX 예외 처리, 시연 영상 제작, 경진대회 발표 (8/26)

## 🛠️ 2. 단계별 세부 과업 명세 (WBS Detail Tasks)

### 📋 Phase 1. 기획 및 설계 (Planning & Design)
1. **기획안 작성**: 공통 완료
2. **UI/UX 화면 설계**: 피그마 퍼블리싱 및 컴포넌트 설계 (공통 진행)
3. **데이터베이스 설계 & ERD 작성**: 11개 테이블 물리 모델링
4. **기능 명세서 & WBS 작성**: 공통 작성
5. **외부/공공 데이터 수집 & API 설계**: 건축물대장, TOPIS, Tmap, ODsay, Naver Local API

---

### ⚙️ Phase 2. 개발 준비 (Dev Setup)
1. **기술 스택 선정**: Vue 3 + Spring Legacy/Boot + MyBatis + MySQL
2. **AI 규칙 정의**: `agent.md` 작성
3. **GitHub 환경**: Repository 생성, 브랜치 전략(`main` ➔ `develop` ➔ `feature/*`), 커밋 컨벤션 정의
4. **프로젝트 구조**: 디렉토리 스키마, 공통 환경 설정, Docker CI/CD 배포 파이프라인

---

### 💻 Phase 3. 파트별 세부 구현 과업 (Core & Main Features)

#### 🔐 1) 인증 및 회원 (Auth & User) - 담당: 구혜성
- **FE**: 로그인 페이지, 아이디/비밀번호 찾기, 회원가입 페이지, 마이페이지 프로필 UI
- **BE**: 로그인 API (JWT), 아이디 찾기, 비밀번호 변경, 중복 확인, 회원가입 API, 프로필 수정, 로그아웃, 회원 탈퇴

#### 🧭 2) 온보딩 및 설정 (Onboarding) - 담당: 안효선
- **FE**: 초개인화 온보딩 Step 1~5 폼, 지도 사이드바 온보딩 요약 패널, 마이페이지 온보딩 요약
- **BE**: 목적지 키워드 검색/좌표 선택 API, 온보딩 데이터 수집/저장/조회/수정/초기화 API

#### 🛍️ 3) 편의시설 필터링 & 댓글 (Amenities & Tag) - 담당: 송은지
- **FE**: 편의시설 커스텀 필터 UI, 댓글 목록/작성 폼, 댓글 기반 특징 태그 뱃지, 주변 편의시설 차트바 패널
- **BE**: 편의시설 조건 추가/삭제/상세필터/적용 API, 댓글 작성/조회 API, 태그 집계 API, 편의시설 도보시간 산출 API

#### 🗺️ 4) 지도 탐색 & 매물 관리 (Map & Property) - 담당: 김민준
- **FE**: 매물 카드/리스트 UI, 메인 지도 렌더링, 커스텀 마커 UI, 매물 상세 기본 정보 패널 UI
- **BE**: 매물 목록 조회 및 5종 정렬 API, 주 목적지 마커 / 매물 위치 마커 API, 매물 기본 정보 조회 API

#### 🛡️ 5) 안전 귀갓길 & CPTED 알고리즘 (Safety) - 담당: 김병승
- **FE**: 지도 내 안전 귀갓길 경로 표시 (Glowing Line), 경로 투표 패널 UI (오버레이 모달), 안전 점수 뱃지 및 5축 차트, 안전 인프라 세부 현황 패널
- **BE**: Tmap 보행자 API 연동 안전 경로 탐색 API, CPTED V1 감산 점수 산출 알고리즘 연동

#### ⏸️ 6) 보류 및 Extra 기능 (Pending / Extra)
- 사용자 맞춤 대출 상품 추천 API (시간 여력 시 착수)
- AI 기반 음성 매물 검색 및 경로 길 안내 (보류)

---

### 🧪 Phase 4. QA, 테스트 & 배포 (QA & Infra)
1. **QA & Testing**: 단위 테스트, 통합 테스트, API 연동 테스트, UI/UX 개선 (공통)
2. **Infra & Deployment**: Docker 컨테이너화, Railway / Cloud 서버 배포
